# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.x     | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Nexus-DevFlow:

1. **Do NOT** open a public issue.
2. Report the vulnerability privately via GitHub Security Advisories or by contacting the maintainers directly.
3. Include detailed steps to reproduce the vulnerability and any affected components or CLI commands.

We will review and acknowledge security reports within 48 hours.
