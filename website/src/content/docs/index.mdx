## สถาปัตยกรรมหลักของ Nexus DevFlow 2.0

<CardGrid>
	<Card title="🏎️ Dual-Track Delivery Model" icon="rocket">
		เลือกความเร็วได้ตามลักษณะงาน: **Fast-Track (4 ขั้นตอน)** ด้วย Living Spec (<code>spec.md</code>) แผ่นเดียวจบ หรือ **Deep-Track (8 ขั้นตอน)** แยก Stage ชัดเจน
	</Card>
	<Card title="💡 Idea Capture Inbox (/idea)" icon="pencil">
		จดบันทึกไอเดียด่วนพร้อม AI ช่วยวิเคราะห์ความเป็นไปได้ (Feasibility), Business Value และสรุป Key Points ลง <code>devflow/ideas.md</code> อัตโนมัติ
	</Card>
	<Card title="🧩 Multi-AI Engine Adapters" icon="puzzle">
		รองรับทั้ง **Google Antigravity**, **Claude Code**, และ **OpenAI Codex** ผ่าน Canonical Commands และ Single Source of Truth
	</Card>
	<Card title="🛡️ Findings Ledger & Strict QA" icon="warning">
		ระบบ State Machine ตรวจสอบบั๊กและช่องโหว่ความปลอดภัย (P0-P3) ที่ไม่อนุญาตให้ปิดงานจนกว่าจะได้รับการแก้ไขและตรวจสอบซ้ำ
	</Card>
	<Card title="📊 Interactive Standalone HTML Reports" icon="document">
		สร้างรายงานส่งมอบงานแบบ Single-File Standalone HTML Dashboard ผ่านคำสั่ง <code>/report:html</code> พร้อมคู่มือ Try Guide
	</Card>
	<Card title="🧭 Smart State Inspector (/devflow)" icon="magnifier">
		ตรวจเช็คสถานะ Workspace และแนะนำคำสั่งถัดไปที่ถูกต้องทันทีตามบริบทจริงของโครงการ
	</Card>
</CardGrid>
