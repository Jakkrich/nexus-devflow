เริ่มต้นใช้งาน Nexus-DevFlow

เรียนรู้วิธีติดตั้ง Nexus-DevFlow ลงในโปรเจกต์ใหม่หรือโปรเจกต์ที่มีอยู่เดิม และเริ่มพัฒนาฟีเจอร์แรกผ่านวงจร 4-Stage Task-Isolated Living Spec Lifecycle

เวอร์ชัน: v2.18.0 ใช้ได้กับทุก Tech Stack Task-Isolated Living Spec

ภาพรวม

Nexus-DevFlow ติดตั้งเลเยอร์เวิร์กโฟลว์อัจฉริยะสำหรับ AI Coding Agent ลงในโปรเจกต์ของคุณ โดยไม่ดัดแปลงสถาปัตยกรรมของแอปพลิเคชัน และไม่มีภาระ Runtime เพิ่มเติม ช่วยให้ AI Coding Agent (Google Antigravity, Claude Code, OpenAI Codex, GitHub Copilot, OpenCode) มีความจำถาวรและขอบเขตการตรวจทานที่ชัดเจน

ไร้การผูกขาด (Zero Lock-In)

โค้ดทั้งหมดเป็นของคุณ 100% หากต้องการยกเลิกการใช้งาน DevFlow ในอนาคต แอปพลิเคชันของคุณยังคงทำงานต่อไปได้ตามปกติโดยไม่มี dependency ตกค้าง

สิ่งที่ต้องมีก่อนเริ่มใช้งาน

  • Node.js: เวอร์ชัน 18.17 หรือใหม่กว่า
  • Git: มีการกำหนดค่า Git repository (git init)
  • AI Coding Assistant: หนึ่งในเครื่องมือที่รองรับ (Google Antigravity IDE, Claude Code, OpenAI Codex CLI, GitHub Copilot, Gemini CLI หรือ OpenCode)

ขั้นตอนการติดตั้ง

01

สร้างโครงร่างแอปพลิเคชัน (Scaffold)

สร้างแอปพลิเคชันของคุณด้วยภาษาและเฟรมเวิร์กที่ต้องการก่อน

# ตัวอย่างสร้างด้วย Vite
npm create vite@latest my-app
cd my-app
git init
02

ติดตั้ง Nexus-DevFlow

รันคำสั่งติดตั้งเพื่อวางเลเยอร์เวิร์กโฟลว์ลงในโปรเจกต์ของคุณ

npx -y nexus-devflow -y
03

ปรับแต่งเวิร์กโฟลว์ให้เข้ากับโปรเจกต์

ในหน้าต่างแชตของ AI assistant รันคำสั่ง /onboard (สำหรับโปรเจกต์ใหม่) หรือ /adopt (สำหรับโปรเจกต์เดิมที่มีอยู่แล้ว)

/onboard
04

รวบรวมบริบทโปรเจกต์

สร้าง Living Source of Truth ในไฟล์ devflow/context/project-overview.md

/overview

พัฒนาฟีเจอร์แรกของคุณ

ทุกการพัฒนาใน Nexus-DevFlow ดำเนินการผ่านวงจร 4 ขั้นตอนที่รัดกุมและปลอดภัย: 

/feature (หรือ /fix) ──▶ /implement ──▶ /check ──▶ /complete

1. ร่าง Living Spec ด้วยคำสั่ง /feature

กำหนด Task Run ID เฉพาะ (เช่น devflow/context/{xxx-slug}/) และร่าง spec.md ก่อนเริ่มเขียนโค้ด: 

/feature 1

2. พัฒนาด้วยวินัย Strict TDD ด้วยคำสั่ง /implement

ทำงานตามรายการงานด้วยวินัย Red-Green-Refactor พร้อมบันทึกผลการทดสอบเชิงประจักษ์: 

/implement 089

3. ตรวจสอบคุณภาพระดับ Senior QA ด้วยคำสั่ง /check

รันเมทริกซ์การตรวจสอบหลายมิติ (Typecheck, Lint, Test suites, manual proof): 

/check 089

4. บันทึกประวัติและผสานโค้ดด้วยคำสั่ง /complete

จัดเก็บเอกสารลงใน devflow/history/features/{xxx-slug}.md, ลบโฟลเดอร์ทำงานชั่วคราว และทำการ Squash-merge: 

/complete 089
