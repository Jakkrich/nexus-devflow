Workflow Surface Map (แผนผังคำสั่ง 15 Core Skills)

แผนผังและโครงสร้างคำสั่งมาตรฐานทั้ง 15 Core Skills ใน Nexus-DevFlow พร้อมรูปแบบการเรียกใช้งานข้ามทุก AI Assistant

Workflow Surface CoreSkills Taxonomy Commands Adapters

รูปแบบการเรียกใช้คำสั่ง (Universal Invocation)

Nexus-DevFlow กำหนดให้แต่ละคำสั่งมี ชื่อมาตรฐานหนึ่งเดียว (One Canonical Name) และสามารถเรียกใช้ได้ตามไวยากรณ์ของ AI Assistant แต่ละค่าย:

สไตล์การเรียกคำสั่งเครื่องมือที่รองรับตัวอย่างการเรียกใช้
Slash Prefix (/)Google Antigravity, Claude Code, Gemini CLI/feature, /implement, /check, /complete
Dollar Prefix ($)OpenAI Codex CLI$feature, $autopilot --all, $devflow
Plain Canonical NameGitHub Copilot, Generic Terminals, OpenCode, Aiderfeature 1, implement, check

1. กลุ่มคำสั่งวงจรชีวิตการพัฒนาและส่งมอบอัตโนมัติ (Delivery Core Skills - 6 Skills)

คำสั่งหมวดหมู่บทบาทหน้าที่อาร์ติแฟกต์หลัก
featureSpec & Planพรีวิวขอบเขต (--preview), Adaptive Pre-Flight Clarification และร่าง Living Spec (--check)context/{xxx-slug}/spec.md
fixSpec & Planร่าง Fix Spec สำหรับการแก้ไขบั๊กหรือการปรับปรุงเร่งด่วนcontext/{xxx-slug}/spec.md
implementExecutionดำเนินการพัฒนาตาม Task Checklist ด้วยวินัย Strict TDDcontext/{xxx-slug}/spec.md
checkQuality GateSenior QA Dual-Axis Verification และ /check guide สำหรับคู่มือทดสอบด้วยตนเองcontext/{xxx-slug}/spec.md
completeDeliveryสรุป Release Digest, ย้ายเข้า History Archive และ Squash-Mergehistory/features/
autopilotAutomationรัน 1 ฟีเจอร์หรือคิวต่อเนื่องในเครื่อง (--all / --max / --merge)history/features/

2. กลุ่มคำสั่งเตรียมความพร้อมและสำรวจ (Pre-Flight Suite - 3 Skills)

คำสั่งหมวดหมู่บทบาทหน้าที่อาร์ติแฟกต์หลัก
ideaBacklogบันทึกไอเดียพร้อมประเมิน AI Feasibility Score & Valuedevflow/ideas.md
exploreIdeationวิเคราะห์โค้ดและเทียบทางเลือก 2–3 แบบ (Brainstorm mode) แบบ Read-OnlySession Read-Only
discoveryExploration & SAสำรวจ Roadmap/ฟีเจอร์, แปลงสเปกหลายฟอร์แมต (REQ-ID), สัมภาษณ์ Socratic (--grill) & ADRdiscoveries/, decisions/

3. กลุ่มคำสั่งตั้งค่า, คุณภาพ และศูนย์กลาง (Setup, Quality & Hub - 6 Skills + Opt-in Extensions)

คำสั่งหน้าที่คำสั่งหน้าที่
devflowศูนย์รวมตรวจสถานะ (--exec), doctor, และ Legacy Routingoverviewคอมไพล์บริบทโปรเจกต์ลง project-overview.md
onboardตั้งค่าโปรเจกต์ใหม่และ auto-detect brownfield (--adopt)debugวินิจฉัย 2-Track (Fast trace หรือ Scientific 6-phase)
auditสแกน YAGNI, Quality, Security, Perf, Tests + independentprototypeสร้าง Mockup HTML/CSS จำลองหน้าจอแบบ Static

Opt-in Tier-2 Extensions (ติดตั้งเฉพาะเมื่อต้องการใช้ด้วย npx nexus-devflow skill add <name>): setup-tests (รวม Playwright browser), ci, release, rollback, vendor, convert-any-to-md, browseros-neo, archify, diagram-design
