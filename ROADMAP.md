# Nexus-DevFlow Roadmap

Strategic direction and planned evolution for Nexus-DevFlow.

## Strategic Direction

Nexus-DevFlow aims to provide the premier stage-based agentic workflow layer for building production software with AI coding assistants (Google Antigravity, OpenAI Codex, Claude Code, Cursor, Gemini CLI, Aider, and Zed).

## Phases

| Phase | Description | Target Status |
| :--- | :--- | :--- |
| **Phase 1: Foundation** | Blueprint-style architecture, NPX overlay installer, multi-tool adapters (`.agents/skills`, `.claude/skills`). | **Completed (v2.0)** |
| **Phase 2: Ecosystem** | Extended skill evaluations, automated release tools, and enhanced stage templates. | **Active Focus** |
| **Phase 3: Integration** | IDE sidecar integration and real-time stage dashboard. | **Planned** |

## Current Focus

- Elevating installer overlay stability across cross-platform environments.
- Expanding skill routing evaluation benchmarks to 100% accuracy.
- Maintaining clean markdown-first stage contracts under `devflow/`.
