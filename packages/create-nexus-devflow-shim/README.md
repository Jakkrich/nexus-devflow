# create-nexus-devflow

Official Unscoped Initializer for **Nexus-DevFlow** — Enterprise-Grade Agentic Workflow Layer for AI coding agents.

Supports standard npm init / create shorthand:

```bash
# Recommended initialization
npm create nexus-devflow

# Or using other package managers:
pnpm create nexus-devflow
bun create nexus-devflow
yarn create nexus-devflow
```
