# nexus-devflow

Official Unscoped CLI for **Nexus-DevFlow** — Enterprise-Grade Agentic Workflow Layer supporting **The 3-Pillars Model & Pure Task-Isolated Living Spec Model** for AI coding agents (Google Antigravity, OpenAI Codex, Claude Code, Cursor, Copilot).

[![MIT license](https://img.shields.io/npm/l/nexus-devflow?style=flat-square&color=155eef)](LICENSE)

---

## 🚀 Quick Start

Run directly without installation:

```bash
# Overlay Nexus-DevFlow into your project
npx nexus-devflow

# Launch interactive Web Dashboard
npx nexus-devflow dashboard

# Install all recommended community skills
npx nexus-devflow skill add --recommended

# Inspect project status and active living spec
npx nexus-devflow status
```

For full documentation and advanced commands, visit the [Nexus-DevFlow Repository](https://github.com/Jakkrich/nexus-devflow).
