01

What (คืออะไร & ทำอะไรได้บ้าง)

/setup-tests คือคำสั่งติดตั้งหรือปรับมาตรฐานระบบ Unit Testing ให้เข้ากับภาษาและเฟรมเวิร์กของโปรเจกต์คุณแบบอัตโนมัติ โดยจะเลือกใช้ Test Runner ที่เบาและตรงกับภาษามากที่สุด พร้อมสร้างตัวอย่างเทสต์ 1 ไฟล์และผูกคำสั่งเข้ากับ AGENTS.md ทันที

  • Automatic Stack Detection — ตรวจจับภาษาและรันไทม์ (TypeScript, JavaScript, Python, Go, Rust)
  • Minimalist Config — ติดตั้งเฉพาะแพ็กเกจที่จำเป็นที่สุด ไม่ใส่ของหนักอย่าง mock framework เกินความจำเป็น
  • Example Test Generation — สร้างตัวอย่างเทสต์ที่รันผ่านจริง 1 ไฟล์ เพื่อยืนยันว่า harness ทำงานได้ 100%
02

Why (ทำไมต้องใช้ & ประโยชน์ที่ได้รับ)

  • เปิดทางสู่ Quality Gate — หากโปรเจกต์ไม่มีคำสั่งเทสต์ AI จะไม่สามารถรัน Test-Driven Development (TDD) ได้
  • ประหยัดเวลาตั้งค่า — ไม่ต้องค้นหาและเขียน config ด้วยตัวเอง AI ติดตั้งให้พร้อมรันได้ในคำสั่งเดียว
  • รักษาความน่าเชื่อถือ — โค้ดทุกบรรทัดใน /implement จะมีเทสต์ยืนยันความถูกต้อง ป้องกันการพังในอนาคต
03

Who (เหมาะสำหรับใคร)

  • ผู้เริ่มต้นสร้างโปรเจกต์ใหม่ — ที่เพิ่งรัน /onboard และต้องการวางรากฐานการเขียนเทสต์ทันที
  • โปรเจกต์เดิมที่ยังไม่มีเทสต์ (Brownfield) — ที่ต้องการเพิ่มความน่าเชื่อถือให้โค้ดก่อนเริ่มทำฟีเจอร์ใหม่
04

Where (ใช้กับส่วนไหน & สิ่งที่สร้าง)

💡
Living Contract: คำสั่งเทสต์ที่ติดตั้งสำเร็จจะถูกบันทึกลงใน AGENTS.md เพื่อให้ Agent ทุกตัวในโปรเจกต์ใช้คำสั่งเดียวกันเสมอ
ภาษา / รันไทม์ Test Runner แนะนำ สถานะ
TypeScript / JavaScript Vitest หรือ Jest SUPPORTED
Python pytest SUPPORTED
Go / Rust go test / cargo test (Built-in) SUPPORTED
05

When (ควรใช้ตอนไหน & ลำดับขั้นตอน)

1
ตรวจสอบ Stack — ตรวจจับ package manager lockfile และ dependencies
2
เลือก Runner — เลือก test runner ที่เบาและตรงกับภาษามากที่สุด
3
ติดตั้ง Config & ตัวอย่างเทสต์ — สร้างไฟล์ config และตัวอย่างเทสต์ที่รันผ่าน
4
รัน Verify — รันเทสต์ยืนยันว่าผ่านสมบูรณ์ 100%
5
อัปเดต AGENTS.md — บันทึกคำสั่งเทสต์เข้าสู่ Source of Truth
