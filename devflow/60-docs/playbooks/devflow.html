01

What (คืออะไร & ทำอะไรได้บ้าง)

/devflow คือ "แผนที่และเข็มทิศนำทาง" ของระบบ เมื่อคุณกลับมาเปิดโปรเจกต์ใหม่ หรือไม่แน่ใจว่าตอนนี้โปรเจกต์ทำค้างอยู่ที่ขั้นตอนไหน และควรสั่งอะไรต่อ เพียงพิมพ์ /devflow ระบบจะสแกนบริบทงานปัจจุบันและแนะนำคำสั่งที่ควรทำทันที

  • State Inspection — ตรวจสอบ task context ใน devflow/context/{xxx-slug}/, discoveries และ backlog
  • Intent Routing — แปลงคำสั่งภาษาคนเป็นคำสั่ง DevFlow ที่ถูกต้องและตรงเป้าหมายที่สุด
  • Zero Guesswork — ตัดความสับสนของ Agent และผู้ใช้ แนะนำคำสั่งที่แม่นยำ 100%
02

Why (ทำไมต้องใช้ & หัวใจ 4 สเต็ป)

Nexus-DevFlow ยึดหลัก Task-Isolated Living Spec Model เพื่อป้องกันไม่ให้บริบทงานล้น (Token Bloat) และคุมคุณภาพด้วยลูป 4 ขั้นตอน:

1
1. /feature (หรือ /fix) — วางแผน กำหนด living spec และขั้นตอนใน spec.md
2
2. /implement — แยก branch ลงมือเขียนโค้ดตามแผน พร้อม TDD Red-Green-Refactor
3
3. /check — Senior QA review ตรวจสอบ Type, Lint, Test และ Multi-lane proof
4
4. /complete — Final safety pass อัปเดตประวัติ HISTORY.md และ squash-merge
03

Who (เหมาะสำหรับใคร)

  • Developers ทุกระดับ — ที่เริ่มเซสชันใหม่แล้วต้องการต่อติดกับงานเดิมทันที
  • Tech Leads & Project Managers — ที่ต้องการตรวจภาพรวมความคืบหน้าของงานทุกสาย
  • AI Coding Agents — ใช้เป็น Router จุดแรกเมื่อผู้ใช้ส่งโจทย์แบบกว้างหรือคำสั่งที่ไม่ชัดเจน
04

Where (ใช้กับส่วนไหน & ความปลอดภัย)

💡
Safe & Read-Only: /devflow เป็นคำสั่งอ่านสถานะอย่างเดียว จะไม่มีการแก้ไขหรือลบโค้ดโดยพลการ ตรวจสอบจากโครงสร้างโฟลเดอร์จริงเสมอ
โฟลเดอร์บริบท (3-Pillars) สถานะ บทบาทหน้าที่
🔮 Future (Backlog) ACTIVE ideas.md, project-plan.md, build-plan.md
⚡ Present (Active Context) ACTIVE devflow/context/{xxx-slug}/ แหล่งความจริงของงานปัจจุบัน
📦 Past (History Archive) ACTIVE devflow/history/ คลังบันทึกการส่งมอบงานที่เสร็จสิ้นแล้ว
05

When (ควรใช้ตอนไหน)

  • เมื่อเปิดเซสชันใหม่ — ตรวจสอบว่าโปรเจกต์ค้างอยู่ที่ขั้นตอนไหน
  • เมื่อทำงานเสร็จในสเตจหนึ่ง — เพื่อให้ระบบแนะคำสั่งสำหรับสเต็ปถัดไป
  • เมื่อมีความต้องการใหม่แต่จำชื่อคำสั่งไม่ได้ — พิมพ์ /devflow "บอกความต้องการ" ได้ทันที
06

How (ใช้งานอย่างไร & ตัวอย่างคำสั่งจริง)

zsh — nexus-devflow
❯/devflow
→ Inspecting active tasks in devflow/context/...
✓ Ready: Active run detected. Recommended next command: /check

/devflow help
