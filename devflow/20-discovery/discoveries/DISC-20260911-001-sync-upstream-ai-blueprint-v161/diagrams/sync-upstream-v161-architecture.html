📡 Upstream Synchronization • Discovery DISC-20260911-001

การซิงก์ส่วนขยาย Upstream AI Blueprint (v1.6.1) สู่ Nexus-DevFlow

สถาปัตยกรรม 5 เสาหลักความปลอดภัยและความแม่นยำ: Installer Hardening, Completion Recovery, History Preservation, Local-Only Review, และ Status Evidence Alignment

🛡️ 1. Installer Symlink Rejection

ตรวจสอบปลายทางการติดตั้งก่อนทำการคัดลอกไฟล์ ปฏิเสธ Symbolic Links และ Path ที่ไม่ตรงกับประเภท (Directory vs File) เพื่อป้องกัน Symlink Traversal และ Partial Install

bin/create-nexus-devflow.ts assertDestinationType()

🔄 2. Safe Completion Recovery

สัญญาฟื้นฟูการส่งมอบงานเมื่อระบบขัดข้อง (`completion-recovery.md`) ตรวจจับ JSON Annotation ฝังใน Archive ระบุ Phase ที่ค้างอยู่ (Archived, Committed, Merged) ไร้ข้อมูลสูญหาย

complete/SKILL.md completion-recovery.md

📚 3. Rebuild History Preservation

คงประวัติการพัฒนาเมื่อสร้างฟีเจอร์ใหม่หลัง Rollback ด้วยการตั้งชื่อ `--build-N` (`NN-slug--build-N.md`) ป้องกันการเขียนทับ Archive เดิม และคงความถูกต้องของการอ้างอิง Findings

feature/SKILL.md build-history.md

🔍 4. Local-Only Spec Review

รองรับการทำ Independent Review สำหรับ Living Spec ที่ไม่ได้ commit ลง Git (เช่น Local-only หรือ gitignored) ด้วยการเก็บและตรวจสอบ Snapshot Hash ใน `devflow/.state/review-specs/`

lib/review.ts specSnapshot

⚖️ 5. Status Evidence Alignment

จำแนกสถานะการตรวจสอบ (`classifyWorkEvidence`) ป้องกัน False Ready State เมื่อ `verification failed` พร้อมเตือน Malformed/Unsafe Findings และชี้ทางแก้ไขไปยัง `/implement` หรือ `/doctor`

lib/status.ts classifyWorkEvidence()

Installer Validation ตรวจจับและปฏิเสธ Symbolic Links และ Incompatible Types ก่อนคัดลอกไฟล์ เพิ่ม validateInstallDestinations ใน bin/create-nexus-devflow.ts ป้องกันความเสี่ยง Symlink Escape High / Security
Completion Recovery เพิ่ม completion-recovery.md พร้อม JSON Comment Annotation เพื่อกู้คืนสถานะส่งมอบที่ค้างคา ปรับใช้ใน complete/SKILL.md และ continuous/SKILL.md ให้เข้ากับ Task-Isolated Living Spec High / Robustness

Local-Only Spec Review ตรวจ Snapshot Hash ของ Spec ใน .state/review-specs/ โดยไม่ต้อง Commit ลง Git ปรับปรุง packages/create-nexus-devflow/lib/review.ts เพิ่มฟิลด์ specSnapshot Medium / Parity
