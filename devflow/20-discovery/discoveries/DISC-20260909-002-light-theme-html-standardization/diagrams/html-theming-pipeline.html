☀️ HTML Light Theme Architecture Pipeline

การวิเคราะห์รากเหง้าของ Dark Theme และสถาปัตยกรรมการย้ายสู่ Light Theme ใน Nexus-DevFlow

DISC-20260909-002 Theme: Light (Default)
🗺️ Pipeline Diagram: จากคำขอ HTML สู่ผลลัพธ์ Light Theme ทั่วระบบ

🔍 ที่มาของ Dark Theme เดิม (Root Causes)

1
System Prompt Bias: มีข้อความชี้นำ "vibrant colors, dark modes, glassmorphism" ใน Developer Prompt ของ AI
2
Playbooks Hardcoded: ไฟล์ใน devflow/docs/playbooks/ ฝัง --bg: #0d1117 (GitHub Dark) เอาไว้ตายตัว
3
Archify Default: Template ของ archify มีค่าเริ่มต้นเป็น data-theme="dark"
4
Diagram-Design Templates: ตัวอย่างส่วนใหญ่ถูกจัดเก็บเป็น *-dark.html

☀️ มาตรฐาน Light Theme ใหม่ (Standardization)

✓
Global Policy: ระบุใน coding-standards.md ให้ใช้ Light Theme เป็นค่าเริ่มต้นทุกงาน HTML
✓
Playbooks Modernization: ปรับแก้ CSS ของ Playbooks ทั้งหมดให้ใช้ Slate-50 + Pure White
✓
Archify Parameter: ส่ง data-theme="light" และ ?theme=light เสมอ
✓
Diagram-Design Selection: สลับไปใช้ template.html (Light) เป็นค่าหลัก

🎨 มาตรฐานจานสี Light Theme สำหรับทุกเอกสาร HTML

CSS Variable Color Preview & Hex หน้าที่ในการแสดงผล (Role)
--bg #f8fafc (Slate 50) พื้นหลังหลักของหน้าจอ สว่าง นุ่มตา ไม่ขาวจ้าจนแสบตา
--surface #ffffff (Pure White) พื้นหลังของการ์ด, กล่องเนื้อหา, Section
--surface-border #e2e8f0 (Slate 200) เส้นขอบบาง ตัดแบ่งขอบเขตเนื้อหาอย่างประณีต
--text-heading #0f172a (Slate 900) หัวข้อหลัก คอนทราสต์สูงสุด คมชัด
--text #334155 (Slate 700) ตัวอักษรเนื้อหา อ่านง่าย สบายสายตา
--primary #0284c7 (Sky 600) สีไฮไลต์หลัก สำหรับ Badge และปุ่มกด
--code-bg #f1f5f9 (Slate 100) พื้นหลังสำหรับบล็อกโค้ดและคำสั่ง CLI
