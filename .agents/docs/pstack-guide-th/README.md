# คู่มือใช้งาน pstack (ฉบับภาษาไทย)

> ฉบับแปลภาษาไทยจาก [คู่มือต้นฉบับภาษาอังกฤษ](../README.md) โดยคงเนื้อหา ตัวอย่างคำสั่ง และแนวทางการอธิบายแบบ Lauren Tan (`poteto`) ไว้ครบถ้วน พร้อม **สรุปท้ายบท** ในทุกบท

pstack ทำงานได้ดีที่สุดเมื่อคุณหยุดสั่งงาน agent แบบคุมทุกฝีก้าว (micromanage) แค่บอกว่าคุณอยากได้อะไร และจะรู้ได้อย่างไรว่างานเสร็จสมบูรณ์ `/poteto-mode` จะเลือก playbook ที่เหมาะสม เรียกใช้ skill อื่นๆ ตามจังหวะที่แต่ละขั้นตอนต้องการ แล้วนำหลักฐานกลับมาให้คุณตรวจ คู่มือชุดนี้สอนวิธีคิดและการเขียน prompt แบบนั้นผ่านตัวอย่างที่ใช้งานจริง

สิ่งที่จะได้เรียนรู้ทั้ง 10 บท:

1. [ติดตั้งและตั้งค่า pstack](./01-setup.md) — ติดตั้ง plugin และเลือกโมเดลที่จะใช้งาน
2. [สั่งงานผ่าน `/poteto-mode`](./02-poteto-mode.md) — กำหนดเป้าหมายและปล่อยให้ระบบจับคู่ playbook
3. [ทำความเข้าใจโค้ดก่อนแก้](./03-understand.md) — การสำรวจแบบ read-only รวมถึง `/how`, `/why`, `/teach`, และ `/recall` ก่อนแตะโค้ด
4. [ออกแบบก่อนเขียนโค้ด](./04-design.md) — `/architect`, `/arena`, `/swarm`, `/interrogate`, การทำ prototype และการวางแผนก่อนล็อกโครงสร้าง
5. [ลงมือสร้างและทำความสะอาด diff](./05-build-and-clean.md) — Playbook สำหรับสร้าง/แก้โค้ด, `/tdd`, `/unslop`, และ `/no-comments`
6. [พิสูจน์ผลลัพธ์และเปิด PR](./06-verify-and-ship.md) — พิสูจน์พฤติกรรมบนแอปจริง, formal verification สำหรับเคสที่ test เข้าไม่ถึง, ตรวจตัวเลขด้วย `/benchmark-checklist`, เปิด PR ที่โฟกัสชัด และส่งขึ้น merge
7. [ปล่อยให้ระบบทำงานตอนคุณหลับ](./07-overnight.md) — สร้างความเชื่อใจก่อนเปิด loop, สัญญางานข้ามคืน, decision log ที่ตรวจสอบย้อนหลังได้, รวมถึง Projects และ automations สำหรับรันงานหลายสาย
8. [คุมทิศทางด้วยชื่อ Principle](./08-principles.md) — 24 ชื่อหลักการที่ใช้ดึงสติและเปลี่ยนทิศทางของ agent กลางคัน
9. [ปรับแต่งให้เข้ากับสไตล์ของคุณ](./09-make-it-yours.md) — สร้างโหมดส่วนตัว, ใช้ `/correct` แก้ความผิดพลาดที่เกิดซ้ำ, และวิธีทดสอบ skill อย่างเป็นกลาง
10. [สูตรคำสั่งและกับดักที่ควรเลี่ยง](./10-recipes-and-pitfalls.md) — Prompt พร้อมก๊อปไปใช้ และข้อผิดพลาดที่คนส่วนใหญ่เจอกันคนละครั้ง

รอบแรกแนะนำให้อ่านเรียงตั้งแต่บทที่ 1 ถึง 10 หลังจากนั้นแต่ละบทสามารถเปิดอ่านแยกอิสระได้ทันที

เมื่อติดขัด หรือไม่แน่ใจว่าควรใช้ skill ไหน ให้พิมพ์ [`/poteto-help`](../../../skills/poteto-help/SKILL.md) พร้อมคำถามของคุณ:

```text
/poteto-help which skill should i use to review this branch?
```

ระบบจะตอบคำถาม ส่ง prompt ที่คุณสามารถนำไปวางสั่งงานต่อได้จริง และแนบลิงก์ไปยัง skill หรือหน้าคู่มือที่เป็นที่มาของคำตอบ โดยมันจะยังไม่เริ่มลงมือทำงาน เพราะการรัน pstack ใช้ token จริง จึงรอให้คุณเป็นคนส่ง prompt เมื่อพร้อม คำสั่งนี้จะทำงานเฉพาะตอนที่คุณพิมพ์เรียกเท่านั้น

## ถ้าจำได้แค่เรื่องเดียว

บอกเป้าหมายและวิธีตรวจรับงานให้ agent ด้วยภาษาของคุณเอง:

```text
/poteto-mode the export writes duplicate rows when a retry lands mid-run. repro first, then fix and verify.
```

คุณไม่จำเป็นต้องระบุชื่อ playbook หรือไล่รายชื่อ skill เอง คำว่า "repro first" กับผลลัพธ์ที่ตรวจผ่าน/ไม่ผ่านได้ คือสัญญาณทั้งหมดที่ `/poteto-mode` ต้องการ มันจะจับคู่เข้ากับ Bug fix playbook คัดลอกขั้นตอนลงใน todo list และเรียกใช้ skill ที่ถูกต้องเมื่อถึงแต่ละขั้นเอง
